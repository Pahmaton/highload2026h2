# Рассчётно-пояснительная записка для Курсовой работы по предмету "Проектирование высоконагруженных систем"

## 1. Тема и целевая аудитория

### Тип сервиса
Цифровой банк без отделений, по образцу Т-Банка. Аналоги в России: Т-Банк, Сбер Онлайн, Альфа-Банк, Озон Банк. В мире: Revolut, Nubank, Monzo, Chime.

### Ключевой функционал (MVP)

- Регистрация и вход (по номеру телефона, подтверждение кодом + возможно установление пинкода или вход по faceid)
- Счета и карты (баланс, лента операций с дозагрузкой, поиск и фильтры по истории)
- Переводы по номеру телефона (внутри банка и через СБП)
- Вклады (открытие, пополнение, начисление процентов, закрытие)
- Кредиты (заявка, оценка кредитоспособности, выдача на счёт, график платежей+списание по графику)
- Push-уведомления по каждой операции.

### Ключевые продуктовые решения

- Отделений нет, поэтому недоступность API = недоступность банка
- Баланс считает только сервер, клиент его не кэширует и не пересчитывает
- Списание в два шага: при покупке и по подтверждению от магазина
- Получатель перевода определяется по телефону через запрос в СБП прямо в момент операции
- Проценты по вкладам и кредитам начисляются раз в сутки, не в реальном времени. Ежемесячные платежи по кредитам списываются также - ночью
- Кредитный скоринг "асинхронный": клиент подаёт заявку, решение приходит потом пушем

### Целевая аудитория
Россия, 34 млн MAU, 15,4 млн DAU (II кв. 2026, [1]). Всего клиентов экосистемы — 54,9 млн [2]. Аудитория распределена по 11 часовым поясам, ночного окна с низкой нагрузкой практически нет.

Для сравнения с рынком: через СБП в I кв. 2026 прошло 4,7 млрд операций, ~52 млн в сутки [3].
